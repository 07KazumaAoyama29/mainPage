# 部屋割り

今回の20人用。定員は4人・3人・3人・5人・5人で固定。

## 使い方

1. ログイン後、`/me/` の「部屋割り」を開く。
2. 名前を1行に1人ずつ、20人分貼り付ける。
3. 抽選画面へ進んでから投影し、「抽選開始」を押す。
4. 約2秒のシャッフル後、「部屋1を発表」からボタンを押して1部屋ずつ発表する。
5. 全5部屋の発表後、結果をコピーするか、全員を再抽選する。

名簿・結果の保存機能はない。ページを再読み込みすると最初からになる。
既存の輪講用 `roulette_app` とは独立している。

## サーバー側の設定

`services.py` の `SEPARATE_PAIRS` に今回の2組を直接記述している。
対象者は名簿で `kazuma-a`、`shota`、`keito` と入力する。
照合では前後の空白、英字の大小、全角・半角の差を吸収するが、
日本語の氏名など別名からの自動変換はしない。
ペアの両者が名簿にいる場合に同室を避け、学年は考慮しない。
この設定はHTML・JavaScript・APIのレスポンスには送らない。

全体を均等にシャッフルし、条件を満たさない抽選を丸ごと棄却する。
条件を満たした結果からの人の入れ替えは行わない。

## 検証・反映

`python manage.py test room_draw` で専用テストを実行できる。
モデル追加はないためマイグレーションは不要。
本番反映時は通常のデプロイ手順に沿って静的ファイルも反映する。
